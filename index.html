데이터 분석

엑셀, SQL, Python으로 데이터를 정리하고 필요한 숫자를 뽑습니다. 보고서에 들어갈 숫자가 필요하면 제가 찾아드립니다.

업무 자동화

대시보드(Power BI)

발주와 입고 같은 운영 데이터를 한 화면에서 보도록 만들고, 매달 갱신하는 방법까지 정리해 둡니다.

자주 받는 질문

코딩을 몰라도 함께 작업할 수 있나요?

네. 필요한 것을 말로 설명해 주시면 됩니다. 제가 단계를 나눠서 같이 진행합니다.

어떤 종류의 프로젝트를 주로 하나요?

데이터 대시보드, 업무 자동화, 정적 웹사이트 제작이 많습니다. 반복되는 일을 줄이는 작업이면 대부분 가능합니다.

작업 기간은 보통 얼마나 걸리나요?

간단한 자동화는 하루, 대시보드는 1~2주 정도 걸립니다. 범위를 먼저 정한 다음 일정을 말씀드립니다.

완성된 결과물의 소유권은 누구에게 있나요?

의뢰하신 분에게 있습니다. 소스와 문서를 모두 드립니다.

완성 후에도 직접 수정할 수 있나요?

네. 수정 방법을 문서로 남겨 드리고, 필요하면 짧게 설명도 해 드립니다.
